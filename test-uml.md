# UML Overview

Unified Modeling Language (UML) is a standardized general-purpose modeling language in the field of software engineering. The standard is managed by the Object Management Group (OMG).

## Main UML Diagram Types

### Structure Diagrams
- **Class Diagram**: Shows classes, attributes, operations, and relationships
- **Component Diagram**: Shows how components are wired together
- **Deployment Diagram**: Shows physical deployment of artifacts

### Behavior Diagrams
- **Use Case Diagram**: Shows user-system interactions
- **Sequence Diagram**: Shows message exchange over time
- **Activity Diagram**: Shows flow of control
- **State Machine Diagram**: Shows state transitions

## Key UML Concepts

1. **Class**: A blueprint for objects, defined with attributes and methods
2. **Interface**: A contract that classes can implement
3. **Association**: A relationship between two classes
4. **Inheritance**: A parent-child relationship (Generalization)
5. **Dependency**: A using relationship
6. **Multiplicity**: Defines how many instances are involved (1, *, 0..1, etc.)

UML 2.5.1 is the current version.
