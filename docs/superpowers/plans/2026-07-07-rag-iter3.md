# Iter 3: RAG Implementation Plan

Goal: Add RAG engine with document upload, parsing, vector retrieval, and a management HTML page.

## Tasks

### R1: Install deps + RAG types
- npm install express multer pdf-parse mammoth --legacy-peer-deps
- Create src/rag/types.ts: RagDocument, RagConfig, RagResult

### R2: Document loader + text splitter
- Create src/rag/loader.ts
- Load txt, pdf, md files using @langchain/community document loaders
- Split using RecursiveCharacterTextSplitter (chunk 1000, overlap 200)

### R3: RAG vector store
- Create src/rag/vectorstore.ts
- OpenAIEmbeddings + MemoryVectorStore (persisted to file via JSON)
- addDocuments, search, deleteDocument, listDocuments

### R4: RAG retriever tool
- Create src/rag/retriever.ts
- RAG search function: embed query -> vector search -> format context
- Register as LangChain StructuredTool for the agent

### R5: Express server + upload API
- Create src/server/index.ts
- POST /api/upload (multipart file upload)
- GET /api/documents (list indexed docs)
- DELETE /api/documents/:id (remove doc)
- POST /api/query (test RAG search)

### R6: HTML upload page
- Create src/server/public/index.html
- Drag-and-drop upload, document list, delete buttons
- vanilla HTML + JS, no framework

### R7: Wire RAG into agent + entry point
- Modify src/index.ts: start Express server, register RAG tools
- RAG tool available to agent as search_documents

### R8: Verify
- npx tsc --noEmit
- Test server starts: npx tsx src/server/index.ts
